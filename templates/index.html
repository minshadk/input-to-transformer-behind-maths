📐 The Mathematics of Self-Attention

The Standard Attention Equation
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$
Query ($Q$) $Q = X W_Q$
What the token looks for in other tokens.
Key ($K$) $K = X W_K$
What the token offers to matching queries.
Value ($V$) $V = X W_V$
The actual semantic content to extract.

1. Dot Product ($Q K^T$): Computes directional similarity between each Query and Key vector. High similarity = high compatibility.

2. Scaling by $\sqrt{d_k}$: As dimensions grow, dot products grow large, pushing softmax into flat regions with tiny gradients. Dividing by $\sqrt{d_k} = \sqrt{4} = 2$ keeps gradients healthy.

3. Softmax: Exponentiates and normalizes each row so all weights are in $[0, 1]$ and sum exactly to $1.0$ (a valid probability distribution).

4. Weighted Sum ($A \cdot V$): Blends the Value vectors according to attention weights, producing contextualized token representations.
